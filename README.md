# Учебный frontend-проект «Творчество» — Bootstrap

Bootstrap-вариант многостраничного сайта из КР №1 (`kr1-html-css-shop`).
Тема та же: каталог услуг и работ творческой студии.

## Страницы

- `index.html` — главная: карусель, преимущества, популярные работы, направления, «Об авторе», контакты;
- `catalog.html` — выбор каталогов и товары с фильтрами;
- `product.html` и `products/` — карточка товара, таблица и модальное окно заказа;
- `original.html` — оригинальные работы и корзина;
- `order.html` — формы «Индивидуальный» и «Ориджин»;
- `contacts.html` — соцсети, телефон, почта, адрес и форма;
- `art.html`, `merch.html`, `craft.html`, `animation.html`, `design.html`, `photo.html` — направления;
- `thanks.html` — страница после отправки формы.

## Что используется из Bootstrap 5.3

- сетка, шапка с прайс-листом и меню, карточки и кнопки;
- карусель на главной, аккордеон в дизайне, модальное окно быстрого заказа;
- offcanvas фильтров каталога на телефоне;
- формы с проверкой полей браузером, таблица характеристик, бейджи и хлебные крошки.

Палитра КР №1 сохранена: `#FFF8E7`, `#930500`, `#95BBEA`.
Свои стили — в `css/custom.css`. Фильтры каталога, крафта и фотографий работают на CSS (`:has` и `:checked`). Своего JavaScript нет: по практикам №8–11 его писать не нужно. Подключён только `bootstrap.bundle.min.js` — он нужен меню, карусели, аккордеону, модальному окну и offcanvas. Корзина оригиналов — форма с количеством на странице заказа.
